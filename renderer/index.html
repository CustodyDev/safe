Finalizar caso

      

        
Cuando termine toda la extracción, S.A.F.E. realiza el cierre del caso:

        
  1. Recalcula el SHA-256 de todas las evidencias y verifica la cadena de custodia.
  2. Genera un manifiesto (MANIFEST.json / .sha256) con el hash de cada archivo.
  3. Comprime el caso completo en un único ZIP.
  4. Calcula el SHA-256 del ZIP y lo sella en OpenTimestamps.
  5. Validación final: relee el ZIP y comprueba que cada archivo coincide con el manifiesto y con el hash de su evidencia.
